# Contributing

- All contributions are accepted under the [CLA](CLA.md); sign it by adding
  yourself to [CONTRIBUTORS.md](CONTRIBUTORS.md) in your first pull request.
- **Clean-room rule:** never copy code, shaders, 3D models, textures,
  sounds, UI layouts, names or network protocols from other VR players
  (commercial or not). Feature ideas are fine; implementations must be
  our own. Don't submit decompiled or disassembled code from any app.
- Assets must be self-made (procedural is preferred) or under a license
  that allows relicensing (CC0, public domain). Record the source in
  [THIRD_PARTY.md](THIRD_PARTY.md).
- New native dependencies must be usable without GPL-only options (LGPL,
  MIT, BSD, Apache-2.0, etc.) so the core can be relicensed later.
- Kotlin code: follow the official Kotlin style; keep files focused.
